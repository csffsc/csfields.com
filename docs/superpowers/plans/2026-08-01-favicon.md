# Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dual-tone CF SVG favicon and wire it into the personal site’s HTML head.

**Architecture:** One root-level `favicon.svg` uses embedded CSS with `prefers-color-scheme` to swap background and C colors. `index.html` links it via `<link rel="icon">`. No build step, no PNG/ICO.

**Tech Stack:** Static HTML, SVG with CSS media queries

**Spec:** `docs/superpowers/specs/2026-08-01-favicon-design.md`

---

| File | Responsibility |

### Task 1: Create dual-tone favicon.svg

**Files:**
- Create: `favicon.svg`

- [x] **Step 1: Write the SVG file**

Create `favicon.svg` at the site root with this exact content:

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 32 32" role="img" aria-label="CF">
  <style>
    .bg { fill: #141210; }
    .c { fill: #e8e4dc; }
    .f { fill: #5c7a4a; }
    @media (prefers-color-scheme: light) {
      .bg { fill: #e8e4dc; }
      .c { fill: #141210; }
    }
  </style>
  <rect class="bg" width="32" height="32"/>
  <text
    class="c"
    x="11"
    y="22"
    text-anchor="middle"
    font-family="Georgia, 'Times New Roman', serif"
    font-size="15"
    font-weight="300"
  >C</text>
  <text
    class="f"
    x="21"
    y="22"
    text-anchor="middle"
    font-family="Georgia, 'Times New Roman', serif"
    font-size="15"
    font-weight="300"
    font-style="italic"
  >F</text>
</svg>
```

- [x] **Step 2: Verify file contents**

Run:

```bash
test -f favicon.svg && rg -n "prefers-color-scheme|class=\"bg\"|class=\"c\"|class=\"f\"|#5c7a4a|#141210|#e8e4dc" favicon.svg
```

Expected: file exists; matches include `prefers-color-scheme`, both hex brand colors, and the three CSS classes.

- [x] **Step 3: Commit**

```bash
git add favicon.svg
git commit -m "$(cat <<'EOF'
Add dual-tone CF favicon SVG.

EOF
)"
```

### Task 2: Link favicon in index.html

**Files:**
- Modify: `index.html` (inside `<head>`, immediately after the `<title>` line)

- [x] **Step 1: Add the icon link**

In `index.html`, after:

```html
  <title>Chris Fields</title>
```

insert:

```html
  <link rel="icon" href="/favicon.svg" type="image/svg+xml" />
```

Do not change fonts, styles, or body markup.

- [x] **Step 2: Verify the link is present**

Run:

```bash
rg -n 'rel="icon".*favicon\.svg|favicon\.svg.*rel="icon"' index.html
```

Expected: one match for the icon link pointing at `/favicon.svg`.

- [x] **Step 3: Visual check in browser**

Run a local static server from the repo root (any one of these):

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/` and confirm:
- Browser tab shows CF with italic sage F
- With OS/browser in dark mode: cream C on night ground
- With OS/browser in light mode: dark C on cream ground

- [x] **Step 4: Commit**

```bash
git add index.html
git commit -m "$(cat <<'EOF'
Wire CF favicon into the site head.

EOF
)"
```
